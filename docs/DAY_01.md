## 你的 1 小时

### 0–25 分钟：顺着一条数据读代码

1. 先读 README 的统计口径，再打开 `datacheck/analyzer.py`。
2. 找到 `row = tuple(...)`：首尾空白被清除，一行变成不可修改的元组。
3. 找到 `seen`：保存已经出现过的整行；再次出现就给重复计数加一。
4. 看 `missing`：每列一个计数，最后除以数据行数。只有表头时避免除零。
5. 看 `__main__.py`：只负责参数、文件、JSON 和退出码；统计逻辑可供未来 API 复用。

技术取舍：精确查重简单、结果准确，但需要保留不同记录，内存随数据增长；尚不能宣称支持任意大文件。

### 25–45 分钟：亲自验证

在 PowerShell 运行：

```powershell
Set-Location 'D:\githubupload\daydayup'
python -m datacheck examples/orders.csv
python -m unittest discover -s tests -v
```

核对样例：5 行、4 列、3 缺失、1 重复，重复示例编号为 5。

然后在忽略目录 `reports/` 中亲手建一个 `my-check.csv`（目录不存在时先新建）：

```csv
name,score
Alice,0
Bob,
Alice,0
```

先写下自己的预测，再运行 `python -m datacheck reports/my-check.csv`。应有 3 行、1 个缺失单元格、1 条重复记录，分数 0 不算缺失。

再把最后一行改成 `Alice,0,extra`，重新运行，立即执行 `$LASTEXITCODE`：应为 2，并提示第 4 条记录列数不匹配。保留你的命令和结果，不需要为了提交上传练习文件。
