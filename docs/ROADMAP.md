## 主项目：DataCheck

- 为谁：需要导入或分析 CSV 的开发者、分析人员。
- 解决什么：在使用数据前暴露缺失值、重复数据、结构错误，并保存可解释的质量报告。
- 岗位能力：Python 模块设计、文件与数据处理、异常处理、自动测试；随后补 HTTP API、SQL、持久化与可观察性。
- 首个最小版本：CSV 输入 → 行列／缺失／重复统计 → JSON 输出；错误可定位，测试和样例可运行。
- 后端展示版本：提交小型 CSV → 返回报告及 ID → SQLite 保存 → 按 ID 或分页查询；提供 API 演示和错误示例。
- 验收方式：陌生人按 README 启动，在固定样例上获得固定指标，再尝试异常文件并看到明确错误。
- 用户亲自完成：预测样例结果、运行测试、修改自己的测试样例、解释关键数据结构和错误路径；以后亲自调用 API 并查询数据库。
- 规模边界：先单机小文件同步处理；不提前加入微服务、消息队列、爬虫或机器学习。
