## 技术取舍

- 用标准库 CSV 解析器处理引号／换行，不手写按逗号分割。
- 用 tuple + set 精确查重，代价是内存随不同记录增加。
- 统计逻辑独立于文件与命令行入口，方便以后接入 API。
- 当前以空字符串判断缺失，不替用户猜测 NULL 等业务含义。
