## 目标与实际实现

从空仓库建立 DataCheck CSV 命令行版本，包含统计核心、文件入口、虚构样例、17 项测试、CI 配置、使用说明与每日协作材料。今天只实现 CLI，路线图中的后端服务还未开始。

## 验证证据

- `python -m unittest discover -s tests -v`：17 项通过，退出码 0。

- 首次测试真实发现空白行被当作错误记录，以及测试读取 Windows 中文路径错误文本时编码不一致；分别修复记录跳过逻辑与测试子进程编码设置后通过。
- GitHub Actions 的远端运行尚未核实；Ubuntu、Python 3.11 的结果不能从本地结果推断。

## 技术取舍

- 用标准库 CSV 解析器处理引号／换行，不手写按逗号分割。
- 用 tuple + set 精确查重，代价是内存随不同记录增加。
- 统计逻辑独立于文件与命令行入口，方便以后接入 API。
- 当前以空字符串判断缺失，不替用户猜测 NULL 等业务含义。
